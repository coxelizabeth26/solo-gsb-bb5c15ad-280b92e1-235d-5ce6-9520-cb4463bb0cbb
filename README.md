# SRT 字幕时间轴校准工具

一款**完全本地运行**的字幕时间轴校准 Web 工具：导入 SRT 字幕，通过若干“校准锚点”把原始时间映射到目标时间，实时重算全部字幕的起止时间，校验通过后导出序号与文本不变的新 SRT。校准锚点还可以导出为“锚点方案”JSON，在修订版 SRT（条目增删、时间轴变化但文本保留）上一键复用。主轨校准完成后还可导入**第二份 SRT** 做**双语字幕合并**：按校准后的主时间轴做顺序保持的一对一匹配，导出主文本 + 次轨文本的双语 SRT。还可载入一个本地视频做**同步预览**：按校准后的起止时间叠加字幕、点击字幕行跳转，边校准边核对。

基于 **React 18 + TypeScript + Vite**，纯前端处理，文件不会上传到任何服务器。

## 一条命令启动（Docker）

```bash
docker compose up -d --build
```

启动后访问：

> **http://localhost:8080**

- 容器内端口：`80`（Nginx 托管静态文件）
- 宿主机端口：`8080`（在 `docker-compose.yml` 的 `ports` 中修改，例如 `"9000:80"`）

停止服务：

```bash
docker compose down
```

## 本地开发 / 不用 Docker

要求 Node.js 18+（推荐 20）。

访问 Vite 开发服务器：**http://localhost:5173**


自动化检查（无测试框架，使用 esbuild 打包后在 Node 中运行断言，覆盖时间解析、校准映射、SRT 往返、方案导入导出与冲突裁决、视频同步逻辑、双语合并的候选门槛 / 最优匹配裁决与双语导出）：

## 使用说明

1. 点击 **导入 SRT**，或将 `.srt` 文件直接拖入页面；也可点击 **载入示例** 快速体验。
2. 在任意字幕行点击 **＋ 设为锚点**，锚点绑定该字幕的**原始起始时间**，再把目标起始时间改成期望的值（格式 `HH:MM:SS,mmm`，回车提交、Esc 撤销）。
3. 表格实时显示每条字幕的原始起止时间、偏移量、校准后起止时间与字幕文本，便于对照。
4. （可选）在预览区点击 **选择视频文件** 载入本地视频，边播放边核对校准结果，详见下节。
5. 可随时 **撤销** 最近一次锚点操作（新增 / 删除 / 编辑目标时间 / 应用方案均可撤销）。
6. 全部问题清零后点击 **导出新 SRT**，下载得到 `<原文件名>.aligned.srt`。
7. （可选）主轨校准完成后点击 **导入次轨 SRT（双语合并）**，按校准后时间轴一对一匹配并导出双语 SRT，详见[双语字幕合并](#双语字幕合并把第二份-srt-按校准后的时间轴对上)一节。

## 本地视频同步预览

导入 SRT 后，预览区可载入一个**浏览器可播放**的视频文件（如 MP4/H.264、WebM）做同步核对：

- **纯本地**：视频仅通过对象 URL（`URL.createObjectURL`）在浏览器内使用，不会上传到任何服务器；**替换或卸载视频时会释放旧对象 URL**，页面关闭时一并清理。
- **播放控制**：使用原生控制条播放、暂停、拖动进度，另提供 0.5×–2× 倍速按钮（倍速在替换视频后仍保持）。
- **字幕叠加**：以**校准后**的起止时间为准在画面下方叠加当前字幕；多条字幕时间重叠时按字幕顺序同时展示；校准后为负时间的字幕不提前显示（起始钳到 0，整体为负则不显示）。
- **高亮联动**：播放、拖动进度条或编辑锚点导致映射变化时，表格中当前命中的字幕行会**立即**高亮刷新。
- **点击跳转**：点击任意字幕行，视频跳到其**校准后起始时间**（负时间钳到 0；超出视频时长则停在末尾）。
- **导入新 SRT 时保留已载入的视频**，但播放位置会重置到开头并暂停，便于从头核对新文件。
- 浏览器无法播放所选格式时会提示原因并自动卸载，可换用其他格式重试。

视频预览只影响界面展示，不影响 **导出新 SRT** 与锚点方案的导入导出逻辑。

## 双语字幕合并：把第二份 SRT 按校准后的时间轴对上

主 SRT 校准完成（锚点可保留或继续调整）后，点击工具栏 **导入次轨 SRT（双语合并）** 选择第二份字幕，页面会出现“双语字幕合并”面板：

- **顺序保持的一对一匹配**：以**校准后的主轨时间轴**对照次轨原始时间轴，每条字幕最多参与一次匹配，且匹配对同时按主轨、次轨序号严格递增（不交叉）。
- **候选门槛**：两条字幕必须有**正重叠**，且重叠时长**不少于两条字幕中较短者时长的 50%**（含恰好 50%）；时长非正的字幕不参与。
- **全局最优**：在全部合法匹配中依次按以下目标择优——
  1. **最大化总重叠毫秒数**；
  2. 再**最小化起始时间差（绝对值）总和**；
  3. 仍并列时，选择**次轨序号序列字典序更早**的方案。
- **实时预览**：锚点发生任何变化（新增 / 删除 / 编辑目标时间 / 撤销 / 应用方案）后立即重算匹配，面板逐对列出校准后时间、双方文本、每对的重叠与起始时差，并分别列出**主轨未匹配**与**次轨未匹配**条目。
- **导出规则**：点击 **导出双语 SRT** 下载 `<原文件名>.bilingual.srt`：
  - 沿用主轨**校准后时间码与主轨序号、主文本**；
  - 已匹配的次轨文本**追加为主文本的下一行**（次轨自身时间码与序号不写入）；
  - 未匹配主轨**照常导出**（仅主文本）；
  - 未匹配次轨**仅在面板提示，不写入文件**。
- **错误拦截**：主轨存在任意校验错误（负时间 / 非正时长 / 重叠）时，**导出双语 SRT 按钮禁用**，面板同时提示错误数量；匹配预览仍会实时更新，错误清零后即可导出。
- 点击 **替换次轨 SRT** 可换一份字幕重新匹配，**移除次轨** 则关闭合并面板；导入新的主 SRT 时次轨会自动清除。
- 匹配纯按时序与重叠计算，不依赖文本是否相同，因此适用于不同语言的两份字幕。

## 锚点方案：把一次校准复用于修订版 SRT

当字幕经过修订（增删条目、片头变化导致整体时间轴挪动，但文案大体保留）时，不必重新设置锚点：

1. 在原始字幕上完成校准后，点击 **导出锚点方案**，下载 `<原文件名>.anchor-plan.json`。文件逐个记录锚点的**原始时间、目标时间**，以及对应字幕的**规范化文本**。
2. 导入修订版 SRT 后，点击 **导入锚点方案** 选择该 JSON（也可直接把 `.json` 文件拖入页面）。工具会先弹出**匹配预览**，逐项标出匹配结果；确认无误后点击 **应用全部有效项**（或取消）。
3. 应用作为**一次操作**进入撤销历史，可一键撤销；整个过程只替换校准锚点，**不会修改任何字幕文本**。

### 文本规范化

方案中的文本与当前字幕文本按同一规则规范化后再比较，规范化**仅**做两件事：

- 去除首尾空白；
- 把连续空白（含空格、Tab、CR/LF 换行）合并为单个空格。

不做大小写转换、标点处理等任何其他改写。

### 匹配与冲突规则

预览中每个锚点为以下三种结果之一：

| 结果 | 条件 |
| --- | --- |
| **直接匹配** | 当前字幕中存在一条“原始起始时间”与“规范化文本”都相同的字幕（精确命中优先，即使该文本在全文重复也直接匹配） |
| **文本迁移** | 精确匹配失败，但该规范化文本在当前全部字幕中**恰好出现一次**，则把锚点迁移到该字幕（沿用方案中的目标时间、绑定其新原始时间）；迁移后不得破坏锚点顺序 |
| **冲突（不应用）** | 文本在全文中找不到（**缺失**）、出现多次（**重复**），或迁移后会破坏锚点顺序 / 导致目标时间不严格递增（**顺序冲突**） |

冲突项在预览中整行标红并注明原因，应用时一律跳过；只有全部有效项会被写入。若有效项为零，应用按钮禁用。

### 方案文件格式

```json
{
  "version": 1,
  "anchors": [
    { "source": "00:00:01,000", "target": "00:00:03,000", "text": "第一句字幕文本" },
    { "source": "00:00:42,000", "target": "00:01:00,000", "text": "最后一句字幕文本" }
  ]
}
```

- `version` 为必填版本号；**未知版本一律拒绝导入**。
- 时间为 `HH:MM:SS,mmm` 字符串（解析时兼容点号毫秒分隔符），方案内原始时间与目标时间均须严格递增。
- 字段缺失、类型错误、存在未知字段、JSON 畸形、锚点为空等情况都会被拒绝，**错误原因直接显示在界面上**。

### 校准规则

| 锚点数量 | 映射方式 |
| --- | --- |
| 0 个 | 保留全部原始时间 |
| 1 个 | 以该锚点的 `目标时间 − 原始时间` 为偏移，整体平移所有字幕 |
| 多个 | 相邻锚点之间做分段线性插值；首段之前、末段之后分别沿最近区段的**斜率外推** |

### 合法性约束

- 锚点的**原始时间**严格递增（由字幕原始起始时间唯一确定，同一原始时间不可重复设锚点）。
- 锚点的**目标时间**也必须两两严格递增。
- 非法的目标时间编辑（格式错误、为负、破坏递增顺序）**不会生效**，输入框立即回退到上一个合法值并提示原因。

### 错误标红与导出拦截

映射结果若出现以下情况，相关行会整行标红并注明原因：

- **负时间**：校准后的起始或结束时间小于 0（常见于首段斜率外推）。
- **非正时长**：校准后结束时间 ≤ 起始时间。
- **重叠**：校准后与相邻字幕的时间轴发生交叠。

只要存在任意一条问题字幕，**导出按钮禁用**；可使用顶部“仅错误”筛选快速定位。

## SRT 兼容性

- 兼容 LF / CRLF、UTF-8 BOM、缺失序号块、点号或逗号毫秒分隔符。
- 时间码无法解析的块会被跳过并在导入提示中报告数量。
- 导出时序号文本与字幕文本（含多行与样式标签）原样保留，仅替换时间码。
- 双语合并导出沿用同一规则，仅在已匹配主轨的文本后追加一行次轨文本；未匹配次轨不写入。
